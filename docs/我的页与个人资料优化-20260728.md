# 我的页与个人资料优化

**日期:** 20260728
**状态:** 已完成

## 功能结果

### 我的页顶部

- `bg_profile_header` 由 MainActivity 顶层统一绘制，连续覆盖系统状态栏和个人信息区域。
- “我的”页不显示公共 Title。
- 隐藏 Title 后同步折叠原有 44dp Header 占位，仅保留状态栏安全区域。
- 状态栏、刘海和底部手势区域使用 WindowInsets 动态适配。
- 切换到消息、联系人、发现页时恢复公共标题栏高度和默认背景。
- Tab 切换时同步提交 Fragment，并在同一帧应用顶部样式，避免从“消息”切换到“我的”时出现中间态闪烁。
- 设置列表区域保持原页面底色，小屏滚动时卡片间距不会透出顶部背景。

### 主页个人信息入口

- 主页左上角展示当前用户头像、昵称和用户 ID。
- 点击整个个人信息区域进入账户设置页面。
- 主页只读取与当前登录用户 ID 匹配的资料缓存，避免账号切换后串用上一账号资料。
- “我的”页先绑定本地缓存，再请求服务端资料；服务端资料无变化时不重复刷新界面。

### 账户设置资料加载

- 页面打开时优先读取 `UserProfileStore` 本地缓存并立即展示。
- 本地缓存用户 ID 必须与当前登录用户一致。
- 缓存展示后继续通过 `ServiceManager.getUserService().getUserInfo` 获取服务端资料。
- 服务端资料无变化时不重复刷新界面和缓存。
- 服务端资料变化时更新本地缓存及编辑基准。
- 网络响应不会覆盖用户已编辑但尚未保存的昵称、账号或头像。
- 缓存可用时，网络加载失败继续保留缓存内容。
- 保存成功后同步更新 `ConfigUtils` 和 `UserProfileStore`，返回主页后刷新左上角个人信息。
