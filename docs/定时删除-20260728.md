# 定时删除设计文档

**日期:** 20260728
**复杂度:** Medium
**状态:** 已完成

## 背景与目标

消息页“+”面板已有定时删除占位入口，但只展示选择框和 Toast。目标是参考 snailchat，支持读取、设置和关闭会话消息时效，并让后续发送的消息按所选周期自动失效。

## Tension Scan 结论

- 会话配置和单条消息时效是两层机制：服务端 `msg_life_time` 保存会话选择，JuggleIM SDK `MessageOptions.lifeTime` 决定具体消息销毁时间，两者必须同时接入。
- 群聊入口受 `group_set_msg_life_right` 控制，不能对无权限成员展示可操作入口。
- 转发目标可能不是当前会话，当前会话的时效不能附加到其他目标会话。

## 架构理解

- 核心模式：会话页通过 `MorePlugin` 扩展输入面板功能，通过 `UserService` 访问业务接口，通过消息流接口更新列表。
- 相关模块：聊天输入插件、会话页、业务服务、消息列表和聊天资源。
- 已识别设计模式：插件模式、Service Adapter、Activity 到 Fragment 的消息流契约。
- 假实现区域：现有定时删除选择器未接入配置接口和 SDK 消息时效参数。
- 用户路径：有权限的用户进入“+ → 定时删除”，选择周期或关闭；当前周期在弹层中回显，设置变化以状态消息同步。

## 方案决策

保留现有 `TimedDeletePlugin` 扩展点，在会话页就近维护当前周期。进入会话时读取服务端配置，选择后先保存配置，成功后更新本地状态并发送 `LifeTimeNotifyMessage`。当前会话发送文本、图片、语音、文件及合并消息时统一补充 SDK `MessageOptions.lifeTime`。

弹层采用 App 现有底部弹层视觉语言：白色面板、顶部圆角、居中标题、浅色分割线、蓝色选中勾；周期与 snailchat 保持一致，为 1、7、30、90、180 天，已开启时额外展示关闭入口。

群聊先读取群资料，根据 `group_set_msg_life_right` 与当前角色决定插件是否可见。私聊始终展示。

### 引入/复用的设计模式

- 复用 `MorePlugin` 插件模式，不在会话页硬编码更多面板按钮。
- 复用 `UserService` 作为业务 HTTP 适配层。
- 不新增 Manager 或 Repository；当前状态只服务单个会话页，放在 `ConversationActivity` 内更内聚。

### 预期改动方向

- 增加会话配置 DTO 与查询、保存接口。
- 为输入插件增加动态可见性控制。
- 替换占位选择器并接通配置保存、状态通知与发送参数。
- 消息列表定期移除已到销毁时间的可见消息。

### 副作用与风险

- 配置保存失败时不得提前改变本地周期。
- 群资料加载失败时群聊入口保持隐藏，避免越权操作。
- SDK 以毫秒接收 `lifeTime`，服务端配置按天保存，转换必须集中处理。
- 转发到其他会话时不继承当前会话周期。

## 改动范围

- `ConversationActivity`：配置加载/保存、底部选择弹层、状态通知、发送参数与到期刷新调度。
- `ChatInputActionBar`：支持按群权限动态隐藏或展示插件。
- `MessageListFragment`：移除当前消息窗口中已到销毁时间的消息并重建时间分割项。
- `UserService`、`UserServiceImpl`、`ConversationConfigBean`：接入 `/jim/converconfs/get` 与 `/jim/converconfs/set`。
- 聊天资源：新增中英文周期、状态和错误文案，以及定时删除弹层布局。
- `GroupManagementRoleHelperTest`：覆盖成员、群主、管理员和无效角色的权限位判断。

## 实现声明

- ✅ 真实接入：会话周期通过业务服务端 `converconfs` 接口读取与保存。
- ✅ 真实接入：消息销毁周期通过 JuggleIM SDK `MessageOptions.lifeTime` 写入文本和媒体消息。
- ✅ 真实接入：设置变化通过已注册的 `LifeTimeNotifyMessage` 发送到当前会话。
- ✅ 真实接入：群聊入口权限来自真实群资料中的 `group_set_msg_life_right` 和 `my_role`。
- Mock、Fixture、未实现外部依赖：无。

## Review 结论

- 正确性：配置仅在服务端保存成功后更新；加载期间若收到其他端的新配置通知，旧响应不会覆盖新状态；转发到其他会话不会继承当前会话周期。
- UX-Mapping：覆盖当前选择、关闭入口、配置加载失败、配置保存失败、群权限隐藏和已到期消息刷新。
- 构建验证：`compileDebugJavaWithJavac`、`assembleDebug` 和定向单元测试通过；DEBUG 包已安装并在连接设备上启动，进程保持运行。
- 仓库既有门禁：全量单测仍有 2 个既有失败，Lint 仍有 14 个既有 error；本次新增代码没有新增 Lint 告警。
- 后续风险：Android 已按 `group_set_msg_life_right` 控制入口；服务端 `converconfs/set` 是否校验同一权限需在服务端仓库单独治理。
